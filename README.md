# Wii U Mods

A mod repository for [CoffeeShop](https://github.com/timkicker/coffeeshop), the Wii U mod manager. Add this repo to CoffeeShop to browse and install the mods below on your console.

## Add this repo to CoffeeShop

CoffeeShop has no built-in mod repository. You tell it which repos to load in a `config.json` file on your SD card.

1. Install CoffeeShop by following the [CoffeeShop install guide](https://github.com/timkicker/coffeeshop). The app goes at `SD:/wiiu/apps/coffeeshop/wiiu_mod_store.wuhb`.
2. Create or open `SD:/wiiu/apps/coffeeshop/config.json`.
3. Add this repo's URL to the `repos` list:

   ```json
   {
     "repos": [
       "https://raw.githubusercontent.com/JacksonHoggard/wiiu-mod-repo/main/repo.json"
     ]
   }
   ```

   If you already use other repos, add this URL as another entry in the list. CoffeeShop merges all of them when it starts.
4. Put the SD card back in your Wii U and launch CoffeeShop. The games and mods below show up in the app.

Installed mods go to `SD:/wiiu/sdcafiine/<titleId>/<modId>/`. You need the [Aroma](https://aroma.foryour.cafe/) environment with the SDCafiine plugin to load them.

## Contributing a mod

1. Fork this repository.
2. Add your mod to the right `games/<game>/game.json`. For a new game, create a new folder under `games/` and list its `game.json` path in `repo.json`.
3. Run the validator:

   ```bash
   python3 validate.py              # check structure
   python3 validate.py --check-urls # also check download URLs
   ```

4. Open a pull request. GitHub Actions runs the validator on every PR.

You can also edit the files with the [CoffeeShop Repo Builder](https://tim.kicker.dev/coffeeshop-builder/). Import `https://raw.githubusercontent.com/JacksonHoggard/wiiu-mod-repo/main/repo.json`, make your changes, and export.

### Repo layout

```
repo.json                  ← repo index (lists every game.json)
games/
  mario-kart-8/game.json   ← game info + its mods
  tphd/game.json
  wwhd/game.json
  nsmbu/game.json
  botw/game.json
  splatoon/game.json
  smash-wii-u/game.json
  sm3dw/game.json
  smm/game.json
  pikmin-3/game.json
  minecraft/game.json
```

Mod ZIPs aren't stored in git. Mods whose GameBanana download already has the right layout link straight to GameBanana. The rest are repackaged (with `content/` moved to the ZIP root and a `CREDITS.txt` added) and uploaded as assets on the [`mods-v1` release](https://github.com/JacksonHoggard/wiiu-mod-repo/releases/tag/mods-v1). Release assets must be under 2 GB, so Mario Kart Generations (2.7 GB) is hosted on the [Internet Archive](https://archive.org/details/mario-kart-generations-wiiu-v1.3.1) instead.

### Mod fields

| Field | Required | Description |
|-------|----------|-------------|
| `id` | ✅ | Unique ID, only `a-z 0-9 - _` |
| `name` | ✅ | Display name |
| `author` | ✅ | Author name |
| `version` | ✅ | Version string, e.g. `1.0.0` |
| `description` | ✅ | Short description |
| `download` | ✅ | Direct HTTPS URL to a `.zip` file |
| `type` | ✅ | `"mod"` or `"modpack"` |
| `thumbnail` | ☑️ | Preview image URL (400x225) |
| `screenshots` | ☑️ | List of screenshot URLs (800x450) |
| `includes` | ☑️ | For modpacks: list of mod IDs |
| `releaseDate` | ☑️ | e.g. `"2024-03-15"` |
| `license` | ☑️ | e.g. `"CC BY-NC"` |
| `tags` | ☑️ | e.g. `["skin", "music", "course"]` |
| `fileSize` | ☑️ | ZIP size in bytes |
| `sha256` | ☑️ | 64-char lowercase hex hash of the ZIP. CoffeeShop checks it after download and rejects a mismatch. |
| `requirements` | ☑️ | List of required mods/patches |
| `changelog` | ☑️ | Free-text changelog |

Download URLs must use HTTPS. CoffeeShop blocks plain HTTP.

### Mod ZIP layout

CoffeeShop extracts the ZIP as-is into `SD:/wiiu/sdcafiine/<titleId>/<modId>/`, so `content/` (and `aoc/` for DLC files) must be at the root of the ZIP, not inside another folder:

```
your-mod.zip
├── content/
│   └── ...game files...
└── aoc/          (optional, DLC files)
```

It must be a real `.zip` (not `.7z` or `.rar`) using stored or deflate compression. Cemu graphic packs (a folder with `rules.txt`) and BCML `.bnp` packages need repackaging first.
